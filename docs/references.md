# Reference points

These links are orientation points for the project’s inspirations. The repository uses them as conceptual inputs and does not claim to reproduce any author’s complete philosophy.

- Martin Buber overview, Stanford Encyclopedia of Philosophy: <https://plato.stanford.edu/entries/buber/>
- Douglas Hofstadter, *I Am a Strange Loop*, publisher page: <https://www.hachettebookgroup.com/titles/douglas-r-hofstadter/i-am-a-strange-loop/9780465008377/>
- John von Neumann, “Theory of Self-Reproducing Automata” record: <https://www.sciencedirect.com/science/article/pii/S0019995866902208>

The term “Thought Transfer,” the `I AM` protocol, and the PMCR-O mapping in this repository are original project design choices.
