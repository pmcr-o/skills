# Sample prompts

Use these to start the PMCR-O agent-surface skill. Keep them short and concrete.

## Prompt 1 — expose a service

```text
Expose `ProjectName.OrchestrationService` as a project-scoped PMCR-O agent surface. Simulate the activation envelope and preserve the parent grant.
```

## Prompt 2 — compare scopes

```text
Compare global, personal, and project agent surfaces. Report inheritance, non-widening grants, entrypoints, and the smallest missing contract.
```

## Prompt 3 — check the projection

```text
Check this agent surface from a fresh context. Confirm simulation=true, verified=false, read-only defaults, and a separate checker handoff.
```
