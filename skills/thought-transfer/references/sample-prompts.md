# Sample prompts

Use these to start the Thought Transfer skill. Keep them short and concrete.

## Prompt 1 — render a trail frame

```text
Render this authorized event as a typed Thought Transfer frame with source reference, scope, evidence, simulation status, and next owner.
```

## Prompt 2 — separate the flows

```text
Project this checked trail backward into a redacted training candidate and forward into a bounded product request. Keep both provenance-linked.
```

## Prompt 3 — minimize cross-session transfer

```text
Create the smallest handoff another session needs: validated resources, acceptance criteria, current evidence, unresolved findings, and one unexecuted next seed.
```
