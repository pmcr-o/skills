# Thought Transfer examples

## Purpose

`frame-template.json` defines the smallest first-person role frame for a
bounded philosophical or phase simulation.

## Inputs

The renderer fills `I AM`, `I NOTICE`, `I ASK`, `I REFUSE`, and `I HAND OFF`
from a declared lens and PMCR-O phase envelope.

## Expected output

A labeled role simulation linked to a trail event and explicit limits.

## Evidence and limits

The frame is generated role-play, not a historical quotation, consciousness
claim, or runtime authority grant.
