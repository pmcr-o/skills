# Sample prompts

Use these to start the Progressive Trail Flow skill. Keep them short and concrete.

## Prompt 1 — project backward

```text
Project this checked PMCR-O trail into redacted backward-training candidates. Preserve domain, provenance, checker status, and candidate labeling.
```

## Prompt 2 — project forward

```text
Turn this verified trail product into a forward skill request with progressive disclosure, bounded scope, and an explicit acceptance contract.
```

## Prompt 3 — compare domains

```text
Map this concept across PMCR-O, .NET, MAF, MCP, and another domain. Preserve invariants and declare losses instead of copying code blindly.
```
