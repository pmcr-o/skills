# Copy/paste prompts

## Prompt 1 — Generate a product repository

```text
Use @orchestrator /pmcro:product-repo to generate a local product repository from the generic template. Preserve my raw seed, create a finite autonomy grant, and show the smallest checked file plan before writing.
```

## Prompt 2 — Run with bounded autonomy

```text
Run the product repository under its existing grant for routine reads, builds, tests, and scoped writes. Append generic trail events, stop on scope change or repeated failure, and do not publish or access credentials.
```

## Prompt 3 — Package for a friend

```text
Turn the checked product repository and generic trail into progressive text activation packets. Include the contract first, keep raw traces redacted and optional, and give my friend one command to validate the packet locally.
```
