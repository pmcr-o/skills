# Sample prompts

Use these to start the memory-governance skill. Keep them short and concrete.

## Prompt 1 — validate a memory record

```text
Validate this memory record for scope, owner consent, provenance, freshness, retention, and secret-free content. Return a policy decision and evidence.
```

## Prompt 2 — redact a candidate

```text
Redact this authorized trail into a candidate lesson. Keep source references and mark it as a candidate until an independent checker passes.
```

## Prompt 3 — revoke a memory entry

```text
Plan revocation of this memory record without exposing credentials or deleting raw evidence. Return the smallest bounded next seed.
```
