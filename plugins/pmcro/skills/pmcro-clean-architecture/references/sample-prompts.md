# Sample prompts

Use these to start the Clean Architecture builder. Keep them short and concrete.

## Prompt 1 — plan a .NET application

```text
Plan a .NET Clean Architecture application named `Orders` with a `Customer` entity. Use EntityBase, generic CRUD, Unit of Work, and simulation-only output.
```

## Prompt 2 — reuse a pinned source

```text
Map this exact repository URL, commit, license, and allowed path into the Clean Architecture baseline. Report preserved invariants and unsupported fields before staging.
```

## Prompt 3 — validate runtime boundaries

```text
Validate the architecture plan and its MAF, CodeAct, Harness, and MCP runtime mapping. Do not claim build or runtime evidence without direct execution.
```
