# Sample prompts

Use these to start the Desktop Commander adapter. Keep them short and concrete.

## Prompt 1 — inspect a repository read-only

```text
Use Desktop Commander to list and search a declared repository for planner, maker, checker, reflector, and catalog surfaces. Return exact paths and evidence. Do not write or run a process.
```

## Prompt 2 — specialize a generic child

```text
Use the generic foundation contract to simulate a sample-child specialization for a .NET console output domain. Show inherited folders, typed input/output, validator, sample prompts, and missing evidence. Do not apply it.
```

## Prompt 3 — run a bounded PowerShell proof

```text
Run one named PowerShell validator with a three-second timeout and capped output. Return exit state and evidence; do not execute arbitrary shell text or delete files.
```
