# Example assets

## Purpose

These examples show the minimum manifest, autonomy grant, and generic trail
request for a friend-run product repository.

## Inputs

Use a product intent, repository root, authenticated principal, provider
adapter list, and a non-expired grant. Replace every example placeholder.

## Expected output

Produce a product manifest, grant decision, generic trail, validation output,
checker handoff, and one unexecuted next seed.

## Evidence and limits

Examples are contract fixtures. They do not grant authority, access secrets,
publish a repository, or prove a provider has a live capability.
